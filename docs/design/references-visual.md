# 시각 레퍼런스 분석

`screens.md`의 1순위 두 화면(메인 '오늘', 오버레이)을 위해 실제 제품 화면과 공식 가이드를 봤다. 공식 페이지를 원본 해상도로 캡처해 분석했다 (내부 분석용, 이미지는 저장소에 넣지 않음). 목적은 **스타일 복제가 아니라 시각적 수준과 문법을 잡는 것**이다.

## 오버레이: 떠 있는 위젯의 문법

| 출처 | 본 것 |
|---|---|
| Apple 라이브 액티비티 [HIG](https://developer.apple.com/design/human-interface-guidelines/live-activities) | 불투명한 검은 판, 테두리 없음(어두울 때만 내용 색에 맞춘 가는 키라인). 숫자가 크고 굵다. 대표 색을 핵심 요소에 과감히. 바깥 모서리와 동심인 일정한 여백(잠금 화면 14pt). 조작은 하나. 애니메이션 2초 이내 |
| Sunsama 집중 바 [페이지](https://www.sunsama.com/features/focus-mode) | 흰 카드 한 줄: 할 일 이름(굵게) + 경과 시간(작은 파란 숫자) + **작은 원형 진행 표시** + 구분선 너머 일시정지 버튼 하나 |
| Windows 위젯 [가이드](https://learn.microsoft.com/en-us/windows/apps/design/widgets/widgets-design-fundamentals) | 16px 여백, 4px 배수. 작은 위젯은 조작 하나. 글자 12/14/18/20/28. 단색·그라데이션·이미지 배경 |
| Windows 재질 [Mica](https://learn.microsoft.com/en-us/windows/apps/design/style/mica) · [Acrylic](https://learn.microsoft.com/en-us/windows/apps/design/style/acrylic) | 반투명 아크릴은 잠깐 뜨는 표면(메뉴·플라이아웃)용. 항상 떠 있는 오버레이에는 불투명 판이 맞다 (아크릴은 비활성·절전·고대비에서 어차피 단색으로 바뀜) |
| Raycast [페이지](https://www.raycast.com/) | 어두운 판, 가는 구분선, 단축키는 키캡, 모서리 12px 안팎, 선택 행은 한 단계 밝은 면 |

**지금 오버레이와의 차이 (원인)**

| 지금 | 레퍼런스 |
|---|---|
| 테두리로 상태 구별 (점선·실선·빗금) | 테두리 없음. 상태는 **핵심 요소의 모양과 색**(진행 링, 아이콘)으로 |
| 판·구분선·트랙·체크박스 테두리가 겹침 | 면 하나 + 최소한의 구분 |
| 굵은 고정폭 42px 숫자, 작은 라벨 여러 개 | 큰 숫자(중간~굵게), 라벨은 거의 없음 |
| 강조색 없음 (회색조) | 대표 색 하나를 핵심 요소에 과감히 |
| 모서리 8px (Carbon) | 판 모서리가 크고(16px 안팎) 안쪽 요소가 동심 |
| 조작 버튼 5개 | 조작 하나 (나머지는 메인 창에서) |

## 메인 '오늘': 할 일 앱의 문법

| 출처 | 본 것 |
|---|---|
| Things 3 [페이지](https://culturedcode.com/things/) | 왼쪽 사이드바(받은함·오늘·예정…), 행 사이 구분선 없음, 여백으로 묶음. 할 일 아래에 작은 회색 메타(프로젝트). 오늘 맨 위에 일정 묶음(회색 면), 아래 '오늘 저녁' 구역. 체크박스는 작고 흐린 테두리. 강조색은 구역 제목에만 |
| Linear [페이지](https://linear.app/) | 어두운 테마: 거의 검은 바탕 위 한 단계 밝은 패널, 1px 흐린 테두리, 모서리 8–12. 사이드바 행 32px 안팎, 아이콘 한 열. 메타는 작은 회색 글자와 · 구분 |
| Todoist [페이지](https://www.todoist.com/) | 원형 체크, 행 아래 가는 구분선, 날짜·라벨은 작은 색 글자 |
| Sunsama 집중 화면 | 할 일 제목 크게, 오른쪽에 '실제 / 계획' 작은 라벨과 숫자, 시작 버튼 하나 |

**지금 메인 창과의 차이**

- 위쪽 탭 5개 → 레퍼런스는 **왼쪽 사이드바**. 화면이 늘어날 때도 안정적이고, 오늘·목표·기록 사이를 오가기 쉽다.
- 행마다 알약 배지 3–4개 → 레퍼런스는 **메타 한 줄을 작은 회색 글자로** (`14:00 · 매일 · RC 이번 주 분량`).
- 오른쪽 타이머가 입력 양식 모양 → 레퍼런스는 **지금 할 일 하나를 크게**(Sunsama). 이것은 오버레이와 같은 물건이다.

## 결정

1. **오버레이는 위젯 문법으로 다시 그린다.** 불투명 판, 테두리 없음(어두운 배경 대비용 8% 흰 키라인만), 모서리 16, 여백 16 동심, 큰 숫자(중간 굵기), 진행은 링·막대 중 하나를 강조색으로, 조작은 하나(시작/일시정지).
2. **Carbon은 기반으로 유지한다.** 색 단계·글자 단계·간격은 그대로 쓰고, 컴포넌트 문법(모서리·테두리·밀도)만 화면 성격에 맞춘다. 같은 토큰, 다른 거리.
3. **메인 '오늘'의 지금 할 일 카드 = 오버레이와 같은 컴포넌트.** 가까이서 보는 크기로만 다르다 (전략 8절 일관성).
4. **메인 창은 왼쪽 사이드바 + 구분선 없는 목록 + 메타 한 줄.**
5. 상태 구별(원칙 ⑤)은 테두리 대신 **기호 모양**으로: ▶(대기·시작 가능) · 진행 링(집중) · ‖(일시정지) · +(초과). 회색조에서도 모양이 다르다.
